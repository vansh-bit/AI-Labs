# Goal-Based Agent (Warehouse Navigation)

## Overview
This directory contains the complete submission materials for **AI Laboratory Exercise: Constructing a Goal-Based Agent using an LLM**.

## Contents
- [`agents_lab.pdf`](file:///Users/vanshsharma/Documents/AI%20Labs/Agents/agents_lab.pdf): The original laboratory exercise document.
- [`warehouse_agent.py`](file:///Users/vanshsharma/Documents/AI%20Labs/Agents/warehouse_agent.py): Standalone Python script implementing the warehouse environment, goal-based agent, BFS search algorithm, metrics logging, and path rendering.
- [`agents_notebook.ipynb`](file:///Users/vanshsharma/Documents/AI%20Labs/Agents/agents_notebook.ipynb): Interactive Jupyter notebook for the laboratory.
- [`SUBMISSION_REPORT.md`](file:///Users/vanshsharma/Documents/AI%20Labs/Agents/SUBMISSION_REPORT.md): Comprehensive submission report with answers to all tasks, theoretical explanations, architecture block diagrams, LLM prompt engineering analysis, and experimental results.
